# Dynamic cardiac SPECT (DC-SPECT)

The 80-head dynamic cardiac SPECT system: Gate 10 simulation, system response matrices
(UAMC and OSPool Monte Carlo SRMs) and ACR phantom work.

| Folder | What |
| --- | --- |
| [`geometry/`](geometry/) | Geometry checks (scanner row view). The interactive geometry test is regenerated by qmirt-gate-10-sim `dev/jupyternb/test_cardiac_spect_geometry_config.ipynb` |
| [`simulation/2026-05-13_gate10-sim-planning/`](simulation/2026-05-13_gate10-sim-planning/) | Statistics needed for the Gate 10 SRM (UAMC count distribution; trillions of primaries for larger FOVs) |
| [`simulation/eris-4-trillion-run-stats/`](simulation/eris-4-trillion-run-stats/) | Per-job statistics of the 4-trillion-primary run on the ERIS cluster |
| [`srm/per-head-sensitivity/`](srm/per-head-sensitivity/) | Per-head sensitivity comparison, high vs low Monte Carlo counts; outlier and geometry views |
| [`srm/2026-08_ospool-srm-three-views/`](srm/2026-08_ospool-srm-three-views/) | OSPool SRM per-head and per-pixel projection plots (August 2026, superseded); packed in `archives/` |
| [`srm/uamc-srm-head-maps/`](srm/uamc-srm-head-maps/) | UAMC SRM per-head maps (reverse-x convention); packed in `archives/` |
| [`acr-phantom/simulation/`](acr-phantom/simulation/) | Gate 10 ACR phantom simulation views |
| [`acr-phantom/sim-vs-recon/`](acr-phantom/sim-vs-recon/) | Simulation against reconstruction, slice by slice |
| [`acr-phantom/recon-ospool-srm/`](acr-phantom/recon-ospool-srm/) | ACR reconstructions with the OSPool SRM, by iteration |
| [`acr-phantom/2026-05-16_tc99m-measurement-mle-recon/`](acr-phantom/2026-05-16_tc99m-measurement-mle-recon/) | MLE reconstruction of the Tc-99m ACR measurement (2026-05-16), 60 and 75 mm masks |

The cardiac and brain SRM reconstruction report (2026-09-25) is in
[`../brain-spect/reconstruction/srm-recon-report/`](../brain-spect/reconstruction/srm-recon-report/).

`srm/2026-08_ospool-srm-three-views/ospool_srm_per_pixel_plots.qmd` refers to the
per-pixel images; unzip the archives (see `archives/MANIFEST.md`) before rendering it.
