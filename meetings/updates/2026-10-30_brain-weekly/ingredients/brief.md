## House rules
1. **Every number must come from a file.**
   - Copy a value from `facts.md`, which cites its source, or have a script read the data file.
   - Never invent or round beyond the source.
   - Keep the provenance: an HTML comment `<!-- source: path -->` next to each number block is enough.
2. **Status labels:** each result is FINAL, PROVISIONAL or PLANNED (not run), as in `facts.md`.
3. **Figures:**
   - Generated by Python scripts in `scripts/` (env: `micromamba run -n raytracing env -u DISPLAY python ...`; data are `.npy`/`.npz`/`.json`), or copied from the verified figure list in `figures.md`.
   - Every plot has axis labels with units, a legend, and a caption that says what to look at.
   - Colour-blind-safe palette; consistent colours across figures (GATE grey, gammart blue, reference black, corrections orange/green).
   - Reconstructed images: same grey scale within a comparison panel, a scale bar in mm, and the slice position stated.
4. **Illustrations for complex concepts** (matplotlib schematics or Typst/cetz drawings):
   - converging-pixel geometry and the edge strip (side view: pinhole, walls fanning out, the strip);
   - the reconstruction forward model as a block diagram: image x → attenuation A → first-interaction matrix H → Compton kernel K → + scatter s → expected counts;
   - pinhole resolution terms (aperture term vs detector term, minification);
   - box ⊗ box vs the Gaussian quadrature convention;
   - "information adds per frequency" (uniform vs mixed apertures).
5. **Equations:** numbered, every symbol defined right below, with one worked number for the key formulas.
6. **Citations:**
   - Quarto citations `[@key]` from `references.bib` (to be built from `references_seed.md`).
   - Cite only entries marked full / agent / abstract there, and say "abstract only" where that matters.
   - Quote the Meng-group findings verbatim with section numbers.
   - IEEE-like style: use `csl: ieee.csl` if available, else Quarto's default numeric style.
7. **Readability:**
   - One-page executive summary first, ending with a short "decisions needed" list.
   - Short paragraphs, informative section titles, tables for comparisons.
   - Put long derivations in the appendix.
   - A notation table near the start.
